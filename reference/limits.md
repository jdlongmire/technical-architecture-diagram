# Limits and vocabulary

Generated by `scripts/gen_reference.py` from `scripts/tad/limits.py` and `scripts/tad/styles.py`.
Do not edit by hand. `python3 scripts/make_tad.py --limits` prints the same table.

Boxes grow to fit their text, so these limits do not depend on the layout.

## Enforced limits

| Limit | Value | Applies to |
|---|---|---|
| `NODE_LABEL_MAX_CHARS` | 40 | node label, characters |
| `NODE_LABEL_MAX_LINES` | 2 | node label lines after wrapping at 200px |
| `STEREOTYPE_MAX_CHARS` | 24 | stereotype text (without guillemets) |
| `DETAIL_MAX_CHARS` | 34 | node detail line |

| `ATTR_MAX_LINES` | 10 | compartment lines per block |

| `EDGE_LABEL_MAX_LINE_CHARS` | 30 | each line of an edge label |

| `CONTAINER_LABEL_MAX_CHARS` | 44 | container header |
| `NODES_PER_VIEW_WARN` | 40 | nodes in one view before a warning |
| `NODES_PER_VIEW_MAX` | 70 | nodes in one view before FIX (split or collapse) |
| `EDGES_PER_VIEW_MAX` | 110 | edges in one view before FIX |
| `CONTAINER_DEPTH_MAX` | 4 | container nesting depth |
| `PAGE_MIN_SCALE` | 0.6 | smallest scale allowed when a fixed page size is set |

## Kinds

| Kind | Default direction | Default node shape | Default container type |
|---|---|---|---|
| `network` | AUTO | box | zone |
| `interface` | AUTO | box | system |
| `dataflow` | AUTO | process | trust |
| `bdd` | DOWN | block | group |
| `ibd` | AUTO | part | system |

`AUTO` lays the view out left-to-right and top-down and keeps the one closer to a landscape page. When most ports have fixed east/west sides it uses RIGHT only; mostly north/south, DOWN only.
